# Uxue y Rafael Aristu — Web de arquitectura

Sitio estático para GitHub Pages, con HTML, CSS y JavaScript.

## Estructura
- `index.html`: inicio y cuatro servicios destacados.
- `servicios.html`: explicaciones de obra nueva, rehabilitación, casas modulares, IEE y CEE.
- `proyectos.html`: proyectos.
- `enarakabi.html`: ficha de Casa Rural Enarakabi.
- `estudio.html`: presentación del estudio.
- `contacto.html`: contacto directo, sin formulario.
- `assets/css/styles.css`: estilos compartidos.
- `assets/js/main.js`: menú móvil y año del pie.
- `assets/img/`: fotografías del proyecto anterior.

## Antes de publicar
1. Sustituir los textos provisionales de correo y teléfono en `contacto.html` por datos reales y enlaces `mailto:` / `tel:`.
2. Confirmar textos profesionales, alcance de servicios y detalles de Enarakabi con el estudio.
3. Revisar la autoría y los permisos de todas las fotografías antes de usarlas públicamente. No se han añadido imágenes de Casas del Irati.
4. Sustituir las imágenes de apoyo repetidas por fotografías de cada servicio.
5. Verificar la web en móvil y escritorio.

## Probar en local
Abre la carpeta completa con VS Code y utiliza Live Server sobre `index.html`. No descargues los HTML sueltos: necesitan `assets/`.

## Publicar en GitHub Pages
Sube el contenido de esta carpeta a la raíz de un repositorio, entra en Settings > Pages y selecciona Deploy from a branch > main > / (root).
